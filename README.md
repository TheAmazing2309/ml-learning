# ml-learning
Learning ML with the courses on Huggingface

## Setup

Each course/unit has its own dependencies, kept in a `requirements.txt` in its folder.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r deep-rl/requirements.txt
```

## Running

```bash
source .venv/bin/activate
python deep-rl/unit-1-hands-on.py
```
